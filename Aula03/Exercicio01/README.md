## 🎯 Objetivo

Somar a quantidade de produtos recebidos pela manhã e à tarde para obter o total do dia.

## 🧠 Conceitos aplicados

- Tipo `int` para quantidades inteiras
- Leitura com `%d`

**Bibliotecas:** `stdio.h` · `locale.h`

## 📥 Entradas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `qte_manha` | `int` | Produtos recebidos pela manhã |
| `qte_tarde` | `int` | Produtos recebidos à tarde |

## 📤 Saídas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `qte_total` | `int` | Total de produtos recebidos no dia |

## ⚙️ Lógica

```text
qte_total = qte_manha + qte_tarde
```

## ▶️ Como executar

```bash
# Compilar
gcc exercicio01.c -o exercicio01

# Executar (Windows)
.\exercicio01.exe

# Executar (Linux / macOS)
./exercicio01
```

## 💻 Exemplo de execução

```text
Quantidade recebida pela manhã: 120
Quantidade recebida à tarde: 80
Total de produtos recebidos no dia: 200
```
