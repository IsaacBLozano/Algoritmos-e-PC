## 🎯 Objetivo

Ler duas notas e exibir a média aritmética entre elas.

## 🧠 Conceitos aplicados

- Soma e divisão
- Uso de parênteses para garantir a precedência

**Bibliotecas:** `stdio.h` · `locale.h`

## 📥 Entradas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `nota1` | `float` | Primeira nota |
| `nota2` | `float` | Segunda nota |

## 📤 Saídas

| Variável | Tipo | Descrição |
|----------|------|-----------|
| `media` | `float` | Média aritmética das duas notas |

## ⚙️ Lógica

```text
media = (nota1 + nota2) / 2
```

## ▶️ Como executar

```bash
# Compilar
gcc exercicio05.c -o exercicio05

# Executar (Windows)
.\exercicio05.exe

# Executar (Linux / macOS)
./exercicio05
```

## 💻 Exemplo de execução

```text
Digite a primeira nota: 7
Digite a segunda nota: 8.5
Media aritmética: 7.75
```
