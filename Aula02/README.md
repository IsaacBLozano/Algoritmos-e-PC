## 📖 Sobre a aula

Primeiro contato com a linguagem C: declaração de variáveis, leitura de dados com `scanf`, exibição formatada com `printf` e construção de expressões aritméticas a partir de fórmulas do dia a dia.

## 🧠 Conceitos trabalhados

- Estrutura básica de um programa em C (`#include`, `main`, `return 0`)
- Tipo `float` para valores reais
- Entrada de dados com `scanf` e saída formatada com `printf` (`%.1f`, `%.2f`)
- Operadores aritméticos (`+`, `-`, `*`, `/`) e precedência
- Uso de `setlocale` para acentuação no terminal
